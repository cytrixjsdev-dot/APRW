Documentation

Guides for installing and using APRW scripts.

Getting Started

  1. Download the script you need from the Downloads page.
  2. Extract the contents of the zip file.
  3. Follow the setup steps for that specific script below.

Installation

Each script ships with its own setup steps. As a general rule:

1. Open the linked tool or environment
2. Load / import the script file
3. Run or execute it
4. Confirm the output matches the guide

FAQ

Do I need any dependencies?

All requirements are listed next to each download. In most cases nothing extra is needed.

How do I get updates?

Releases are published on the Downloads page. Re-download once a new version is available.

Where can I report problems?

Open an issue on the GitHub repository for this project.
